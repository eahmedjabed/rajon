# All Over Taxi – DEMO website (practice)

This is a practice copy of the taxi website. All names, numbers, places and prices are fictional.
Use it to learn the GitHub and Netlify steps before you publish the real site.

## Demo admin login
- Go to `/admin` on your Netlify address.
- Username: **demo**
- Password: the one given to you once in the chat. Change it on first sign-in (Account page).

## Steps (same as the real site)
1. Upload all files in this folder to a new GitHub repository (`all-over-taxi-demo`).
2. In Netlify choose **Add new project → Import an existing project** and pick the repository. Do not drag the folder in.
3. Deploy. Open the site, scroll to the bottom and press **Admin Panel**.
4. Sign in, change a phone number or fare, press Save, then refresh the public site to see the change.
5. When you are happy with the practice, delete the demo repository and site, then repeat the steps with the real project.

Note: the taxi animation still uses the artwork from the real client's car. Replace it before publishing any demo publicly.
